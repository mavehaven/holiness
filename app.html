HoloRes Tutorial

Step 1: Upload Your Video

Start by uploading an MP4 video file using the upload area. You can either click to browse or drag and drop your file.

Supported formats: MP4, WebM, OGG

Once uploaded, the video will load and you'll see it in the preview area.

Step 2: Adjust 3D Settings

Use the 3D Effect Adjustments panel to fine-tune your autostereoscopic effect:

  • Number of Views: More views create smoother 3D but require more processing
  • View Separation: Controls the horizontal offset between views
  • 3D Depth: Adjusts the overall intensity of the 3D effect

Experiment with different settings to find the perfect 3D effect

Step 3: Configure Display Settings

For best results, configure the display settings to match your target device:

  • LPI (Lenses per Inch): Match your 3D display's specification
  • DPI (Pixels per Inch): Your display's pixel density
  • Display Width: Physical width of your display in inches

Use presets for common display types or set custom values

Step 4: Export Your 3D Video

Once you're satisfied with the 3D effect, export your video:

  • Export as MP4: Direct video export (requires processing)
  • Export as ZIP: Individual frames for advanced processing

For MP4 conversion, use FFmpeg with the provided command

Pro Tip: For the best quality, export as ZIP and convert using FFmpeg with the command provided in the instructions.
